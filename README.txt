Taller Práctico: Simulador Interactivo y Evaluador de Indicadores de Concentración de Mercado
Organización Industrial - Andres Vallone

Instrucciones de Ejecución Local:
1. Asegúrese de tener instalado Python (versión 3.9 o superior).
2. Abra una terminal en la carpeta del proyecto e instale las dependencias ejecutando:
   pip install -r requirements.txt
3. Ejecute la aplicación web con el comando:
   streamlit run app.py
4. Se abrirá automáticamente una ventana en su navegador web con la aplicación interactiva en funcionamiento.
